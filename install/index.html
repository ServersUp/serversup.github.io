Install ServersUp for Discord game server alerts

Get notified when your community's favorite game servers go up or down.

Free forever. No subscription.

ServersUp polls game servers in the background, and when something changes it notifies everyone who subscribed to that server. No more refreshing official status pages or waiting for maintenance posts that arrive late. New here? Why alerts only fire on change.

Highlights

  • Alerts within about a minute

    Notifications arrive within about a minute of a server status change.

  • Role mentions

    Optionally ping a role when you subscribe, so the right people get notified.

  • Live status, no bot needed

    Check UP and DOWN on the status page without installing anything.

Option 1

Set up the Discord bot

  1. Add the bot to your server with the Add Discord bot button.
  2. Pick or create a channel for updates. Make sure the bot can send messages and read message history in that channel.
  3. Run /subscribe in that channel and pick a game, region and server. Autocomplete helps you fill each field with valid values. Updates are sent to the channel where you run the command.

Option 2

Set up with a webhook

Prefer a webhook? No bot, no permissions needed, no signup. Webhooks post alerts to any channel you choose, without adding the bot to your server.

  1. Click Add via webhook to open the form.
  2. Create a webhook in the channel that should receive alerts (Server Settings, Integrations, Webhooks) and paste its URL into the form.
  3. Pick the game, region and server you want to watch, then set an optional role to mention.
  4. Submit the form. ServersUp posts a test alert to your webhook to confirm it works before saving. Alerts then flow to that channel whenever the server changes status.

Add a webhook subscription

Get alerts in any channel without adding the bot. Create a webhook in that channel, paste it below, pick a game and region, and choose a server, or choose ALL SERVERS for that region to be notified once when every server there is down and once when they all come back up.     As many as you like, across as many games as you like. Follow one server or many, in one channel or several. A single webhook can subscribe to a given server once.

    Watching ALL servers covers every server in a region you pick, like all US servers. You get one alert when every server in that scope is down, and one when they all come back up, instead of a message for each individual server. It is a good fit for region-wide outages or maintenance.
